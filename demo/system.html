2
the foundation — tokens

What's a token, really?

tokens ≈ atoms · Brad Frost

At step 1 you wrote #E5366E straight into the button. So did everyone — the same value, copy-pasted in hundreds of places, with no name. A token fixes that: you name the decision once, and everything points to the name.

💡 think of a phone contact

You don't memorise a number — you save it as "Mom". When her number changes, you edit one contact, not every place you ever wrote it. A token is the same: --brand is the name, the color is the number behind it.

⚠ without tokens
.btn-a {
  background: #E5366E;
}
.btn-b {
  background: #E5366E;
}
.link {
  color: #E5366E;
}
/* …×200 */
✓ with a token
:root {
  --brand: #E5366E;
}

.btn-a {
  background: var(--brand);
}
/* one source.
   change once. */

So we collect those named decisions into a small style guide — the dictionary the whole app looks things up in. Build yours below.

We point both buttons at those tokens — same A and B as before. But this time, watch what happens when you tweak the shared values:
